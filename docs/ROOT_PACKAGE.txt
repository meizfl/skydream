Skydream portable desktop runtime

Put Data/ from Skyrim Legendary Edition 1.9.32 beside Skydream (Skydream.exe
on Windows). Keep all bundled directories/libraries beside the executable.
Launch Skydream without arguments, or pass a game directory explicitly.
No Homebrew or MSYS2 installation is required on the target computer.

Packages contain SDL2, FFmpeg, native vkd3d-shader and their runtime dependencies.
macOS includes Vulkan Loader and MoltenVK. Windows includes Vulkan Loader;
a compatible Vulkan-capable GPU driver must still be installed by its vendor.
Do not mix libraries from different platforms or architectures.

Verification without game assets or a graphics window:
  Skydream --bundle-smoke
This checks embedded game data, generated code, native HLSL compilation and
loading of packaged graphics libraries. It does not validate actual gameplay.
macOS requires macOS 15 or newer; Windows targets Windows 10/11 x86-64.

Sources, dependencies and license metadata are included under share/.
Project source and build instructions: https://github.com/meizfl/skydream
