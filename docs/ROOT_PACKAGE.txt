Skydream desktop development build

Put Data/ from Skyrim Legendary Edition 1.9.32 beside Skydream (Skydream.exe
on Windows). Keep the lib/ directory beside the executable on macOS/Linux.
Launch Skydream without arguments, or pass a game directory explicitly.

This is a native desktop executable, not a shell launcher. Do not mix binaries
or libraries from different platforms or architectures.

The development package currently requires target-system SDL2, FFmpeg and a
native vkd3d-shader 2.0 compiler. macOS graphics also requires Vulkan/MoltenVK.
Headless verification: Skydream --embedded-smoke
GPU rendering/gameplay on macOS and Windows has not been validated by that test.
